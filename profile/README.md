# Mytho Compendium

*A Digital Mythology Encyclopedia*

## Personal Context

Upon initiating Mytho Compendium in February 2026, I brought nearly a decade of native Android development experience but no expertise in mythology, backend engineering, cross-platform architecture, or AI/ML. This project deliberately expands beyond my established domain, providing an opportunity to develop proficiency in Kotlin Multiplatform, server-side development (databases, APIs, cloud infrastructure), and AI/LLM integration while simultaneously acquiring scholarly knowledge in mythological studies.

## Overview

Mytho Compendium is a comprehensive mobile application delivering academically rigorous mythological content through a modern cross-platform mobile architecture (Android, iOS). The project serves as both a production-grade application and an extensive technical exploration of contemporary mobile development practices, split across the following repos:

| Repo | What |
|:---|:---|
| [mytho-compendium-app](https://github.com/Mytho-Compendium/mytho-compendium-app) | Encyclopedia app for world mythologies |
| [mytho-compendium-server](https://github.com/Mytho-Compendium/mytho-compendium-server) | Backend server for the encyclopedia's data |
| [mytho-compendium-content](https://github.com/Mytho-Compendium/mytho-compendium-content) | Content pipeline, mythology research/validation skills, database schemas, ingestion scripts |
| [.github](https://github.com/Mytho-Compendium/.github) | Org profile and shared development conventions (git, tickets, story points) |

## Core Principles

### Content Philosophy

- Prioritize scholarly accuracy through verifiable primary and secondary sources
- Generate culturally-respectful illustrations grounded in historical iconography
- Maintain academic integrity while ensuring content accessibility across user demographics

### Academic Rigor

- Adopt a research-first methodology with scholarly citations and peer-reviewed references
- Preserve content complexity and nuance. Accessibility emerges through thoughtful information architecture rather than oversimplification
